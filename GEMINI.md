## 2. Mandatory Mobile UI Verification Hook (ОБОВ'ЯЗКОВО)

> **CRITICAL — виконується при будь-якій зміні або додаванні функції перед `npm run build` або `git push`.**

При додаванні нової функції, зміні існуючої або модифікації UI, агент **ЗОБОВ'ЯЗАНИЙ** перевірити мобільну версію (320px–430px Android viewport):
1. **Запустити валідатор**: `npm run check:mobile` (скрипт `scripts/check-mobile-ui.mjs` автоматично спрацьовує як prebuild hook та pre-push hook).
2. **Перевірити новий/змінений функціонал на типові мобільні баги**:
   - **Sheet/Dialog**: будь-який `<SheetContent>` з вибором дат (DatePicker, Popover, Combobox, форма) **мусить мати** `onInteractOutside={(e) => e.preventDefault()}`, інакше на мобільному екран закривається при виборі дати або кліку на portal.
   - **Таблиці**: кожна таблиця повинна мати обгортку `overflow-x-auto` або мобільну альтернативу (`hidden md:block` з картковим відображенням на мобільному).
   - **Розміри та відступи**: жодних жорстких `w-[Xpx]` > 320px без префіксів `sm:`/`md:`.
   - **Кнопки та заголовки**: всі рядки з декількома кнопками (`flex items-center justify-between`) повинні мати `flex-wrap` або стакатись на мобільному.
   - **Bottom Nav / Safe Area**: переконатися, що контент не перекривається нижньою панеллю навігації (`pb-[calc(4rem+env(safe-area-inset-bottom))]`).
3. Якщо валідатор знаходить критичні помилки — білд або пуш **не пройдуть**. Необхідно виправити всі зауваження перед тим, як завершувати завдання.
